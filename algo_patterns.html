Паттерн 01

Префиксные суммы (Prefix Sum)

Заранее считаем накопленные суммы элементов массива, чтобы затем отвечать на запрос суммы любого отрезка за O(1) вместо пересчёта каждый раз заново.

Когда использовать

Много запросов суммы диапазона [l, r] на неизменяемом массиве — пересчитывать сумму каждый раз слишком медленно.

Range Sum QuerySubarray Sum Equals K

Пример задачи

Дан массив чисел. Нужно много раз быстро узнавать сумму элементов на отрезке от индекса l до r.

def build_prefix(nums):
    prefix = [0] * (len(nums) + 1)
    for i, num in enumerate(nums):
        prefix[i + 1] = prefix[i] + num
    return prefix

def range_sum(prefix, l, r):
    return prefix[r + 1] - prefix[l]

nums = [2, 4, 1, 5, 3]
prefix = build_prefix(nums)
# сумма на отрезке [1, 3]: 4 + 1 + 5
print(range_sum(prefix, 1, 3))  # 10

Паттерн 02

Два указателя (Two Pointers)

Два индекса двигаются по массиву или строке — навстречу друг другу или в одну сторону — чтобы решить задачу за один проход вместо вложенных циклов.

Когда использовать

Отсортированные массивы, поиск пар с нужной суммой, проверка палиндромов, слияние двух массивов.

Two Sum IIContainer With Most WaterValid Palindrome

Пример задачи

Дан отсортированный массив. Нужно найти два числа, сумма которых равна target.

def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return [l, r]
        elif s < target:
            l += 1
        else:
            r -= 1
    return None

nums = [1, 3, 4, 6, 9]
print(two_sum_sorted(nums, 10))  # [0, 4] -> 1 + 9

Паттерн 03

Скользящее окно (Sliding Window)

Держим «окно» фиксированного или переменного размера и двигаем его по массиву/строке, не пересчитывая всё внутри окна заново на каждом шаге.

Когда использовать

Подотрезки/подстроки максимальной суммы, длины, без повторяющихся символов и подобные задачи «окном».

Longest Substring Without Repeating CharactersMax Sum Subarray of Size K

Пример задачи

Дан массив и число k. Нужно найти максимальную сумму подряд идущих k элементов.

def max_sum_window(nums, k):
    window_sum = sum(nums[:k])
    best = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        best = max(best, window_sum)
    return best

nums = [2, 1, 5, 1, 3, 2]
print(max_sum_window(nums, 3))  # 9 -> [5, 1, 3]

Паттерн 04

Быстрый и медленный указатели (Fast & Slow)

Два указателя двигаются по связному списку с разной скоростью — обычно slow на 1 шаг, fast на 2 — чтобы находить середину списка, циклы и подобное, без лишней памяти.

Когда использовать

Обнаружение цикла в связном списке, поиск середины списка за один проход.

Linked List CycleMiddle of Linked ListHappy Number

Пример задачи

Дан связный список. Нужно определить, есть ли в нём цикл.

class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

def has_cycle(head):
    slow, fast = head, head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

Паттерн 05

Разворот связного списка на месте

Разворачиваем связный список, меняя направление указателя next у каждого узла, без создания нового списка и лишней памяти.

Когда использовать

Задачи на разворот всего списка или его части, разворот по k узлов.

Reverse Linked ListReverse Nodes in k-Group

Пример задачи

Дан связный список 1 → 2 → 3. Развернуть его на месте.

class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

def reverse_list(head):
    prev = None
    curr = head
    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node
    return prev  # новая голова списка

Паттерн 06

Монотонный стек (Monotonic Stack)

Стек, в котором элементы всегда идут в возрастающем или убывающем порядке. Используется, чтобы для каждого элемента быстро найти ближайший больший или меньший сосед.

Когда использовать

Next Greater Element, задачи про гистограммы, «сколько дней ждать потепления».

Next Greater ElementDaily TemperaturesLargest Rectangle in Histogram

Пример задачи

Для каждого элемента массива найти ближайший следующий элемент, который больше его.

def next_greater(nums):
    result = [-1] * len(nums)
    stack = []  # хранит индексы
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            idx = stack.pop()
            result[idx] = num
        stack.append(i)
    return result

nums = [2, 1, 5, 3, 4]
print(next_greater(nums))  # [5, 5, -1, 4, -1]

Паттерн 07

Топ K элементов (Top K Elements)

Используем кучу (heap), чтобы эффективно находить K наибольших или наименьших элементов, не сортируя весь массив целиком.

Когда использовать

Топ K частых слов, K ближайших точек, K-й по величине элемент.

Kth Largest ElementTop K Frequent Elements

Пример задачи

Дан массив чисел. Нужно найти 3 наибольших элемента.

import heapq

def top_k_largest(nums, k):
    return heapq.nlargest(k, nums)

nums = [7, 2, 9, 4, 1, 8]
print(top_k_largest(nums, 3))  # [9, 8, 7]

Паттерн 08

Перекрывающиеся интервалы (Overlapping Intervals)

Сортируем интервалы по началу и последовательно объединяем те, что пересекаются друг с другом.

Когда использовать

Слияние встреч в календаре, объединение диапазонов времени, поиск свободных окон.

Merge IntervalsInsert IntervalMeeting Rooms

Пример задачи

Дан список интервалов. Нужно объединить все пересекающиеся между собой.

def merge_intervals(intervals):
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        last_end = merged[-1][1]
        if start <= last_end:
            merged[-1][1] = max(last_end, end)
        else:
            merged.append([start, end])
    return merged

intervals = [[1,3],[2,6],[8,10],[15,18]]
print(merge_intervals(intervals))  # [[1,6],[8,10],[15,18]]

Паттерн 09

Модифицированный бинарный поиск

Классический бинарный поиск, адаптированный под нестандартные условия — повёрнутый массив, поиск границы диапазона, поиск в матрице.

Когда использовать

Любой отсортированный (или частично отсортированный) массив, где линейный поиск слишком медленный.

Search in Rotated Sorted ArrayFind First and Last Position

Пример задачи

Найти индекс первого элемента, который больше или равен target.

def lower_bound(nums, target):
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

nums = [1, 3, 5, 7, 9, 11]
print(lower_bound(nums, 6))  # 3 -> индекс числа 7

Паттерн 10

Обход бинарного дерева

Способы обойти узлы дерева — in-order, pre-order, post-order, level-order. Каждый порядок даёт свою полезную последовательность значений.

Когда использовать

Практически любые задачи на бинарные деревья и деревья поиска (BST).

Binary Tree Inorder TraversalValidate BST

Пример задачи

Обойти дерево в порядке in-order: левое поддерево → корень → правое поддерево.

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def inorder(node, result=None):
    if result is None:
        result = []
    if node:
        inorder(node.left, result)
        result.append(node.val)
        inorder(node.right, result)
    return result

Паттерн 11

Поиск в глубину (DFS)

Идём вглубь по одной ветке графа или дерева до конца, потом возвращаемся назад и пробуем следующую ветку.

Когда использовать

Обход всех узлов, поиск пути, поиск компонент связности, «острова» на карте.

Number of IslandsClone GraphPath Sum

Пример задачи

Дан граф в виде списка смежности. Найти все узлы, достижимые из стартового.

def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    return visited

graph = {1: [2, 3], 2: [4], 3: [], 4: []}
print(dfs(graph, 1))  # {1, 2, 3, 4}

Паттерн 12

Поиск в ширину (BFS)

Обходим граф или дерево уровень за уровнем — сначала все прямые соседи, потом соседи соседей, и так далее.

Когда использовать

Кратчайший путь в невзвешенном графе, минимальное число шагов до цели.

Word LadderRotting OrangesShortest Path in Binary Matrix

Пример задачи

Найти минимальное число шагов от одного узла графа до другого.

from collections import deque

def bfs_shortest_path(graph, start, target):
    queue = deque([(start, 0)])
    visited = {start}
    while queue:
        node, dist = queue.popleft()
        if node == target:
            return dist
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, dist + 1))
    return -1

graph = {1: [2, 3], 2: [4], 3: [4], 4: []}
print(bfs_shortest_path(graph, 1, 4))  # 2

Паттерн 13

Обход матрицы (Matrix Traversal)

Обход двумерной сетки: по строкам и столбцам, по спирали, зигзагом, или как граф — с помощью DFS/BFS по соседним клеткам.

Когда использовать

Задачи на сетки: острова, игровые поля, спиральный вывод элементов матрицы.

Spiral MatrixNumber of IslandsSet Matrix Zeroes

Пример задачи

Дана матрица. Вывести все её элементы в порядке обхода по спирали.

def spiral_order(matrix):
    result = []
    while matrix:
        result += matrix.pop(0)
        if matrix and matrix[0]:
            for row in matrix:
                result.append(row.pop())
        if matrix:
            result += matrix.pop()[::-1]
        if matrix and matrix[0]:
            for row in matrix[::-1]:
                result.append(row.pop(0))
    return result

matrix = [[1,2,3],[4,5,6],[7,8,9]]
print(spiral_order(matrix))  # [1,2,3,6,9,8,7,4,5]

Паттерн 14

Возврат (Backtracking)

Перебираем варианты, но обрезаем ветку сразу, как только становится понятно, что она не приведёт к решению — вместо перебора вообще всех комбинаций.

Когда использовать

Генерация комбинаций/перестановок/подмножеств, задачи вроде N ферзей, судоку.

SubsetsPermutationsN-QueensSudoku Solver

Пример задачи

Дан массив уникальных чисел. Нужно вывести все его подмножества.

def subsets(nums):
    result = []
    path = []
    def backtrack(start):
        result.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()
    backtrack(0)
    return result

print(subsets([1, 2, 3]))
# [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]

Паттерн 15

Динамическое программирование (DP)

Разбиваем задачу на перекрывающиеся подзадачи и сохраняем уже посчитанные результаты, чтобы не пересчитывать их заново каждый раз.

Когда использовать

Оптимизационные задачи: рюкзак, наибольшая общая подпоследовательность, количество способов что-то сделать.

Climbing StairsCoin ChangeLongest Common SubsequenceKnapsack

Пример задачи

Сколько есть способов подняться по лестнице из n ступеней, если за раз можно пройти 1 или 2 ступени.

def climb_stairs(n):
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

print(climb_stairs(5))  # 8
